# Prévia — Gestão de Frota CPL

Demonstração estática e funcional do módulo de gestão de frota do Sistema de Gestão CPL.

## Publicação

O fluxo em `.github/workflows/deploy-pages.yml` publica automaticamente esta prévia no GitHub Pages a cada atualização enviada para a branch `main`.

Esta demonstração usa dados locais do navegador. O sistema oficial continuará utilizando a API protegida e o PostgreSQL.
